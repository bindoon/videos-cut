# 来源与归属

- **创意参考**：Eian《一座城的年轮》，成都，2026-10-18，https://x.com/EianLu/status/2111662397278847478 。杭州版重新编写解说、画面、镜头与配乐，没有使用成都片子的画面或音轨作为杭州成片。
- **制作方法参考**：Eian，https://x.com/EianLu/status/2115761407774118044 。
- **渲染基础**：LemoLab，Lemo Opuscar，MIT，固定修订 `f17136060781a0068a7951245a3aa7835a7230de`。`vendor/lemo/post.js` 与 `browser.mjs` 源自该项目；原许可随附。https://github.com/lemomo-ai/lemo-opuscar 。
- **建筑数据**：Zhang, Y., Zhao, H. & Long, Y. *CMAB: A Multi-Attribute Building Dataset of China*. Scientific Data 12, 430 (2025). https://doi.org/10.1038/s41597-025-04730-5 。数据版本 2，CC BY 4.0：https://doi.org/10.6084/m9.figshare.27992417.v2 。
- **水系、道路及部分高度**：© OpenStreetMap contributors，ODbL。https://www.openstreetmap.org/copyright 。数据通过公开主 API 和 Nominatim 下载，原始响应保存在 `assets/cache/hangzhou/`。取景、投影、简化与高度融合由本项目执行；派生几何与来源说明一起交付。
- **字体**：Noto Sans SC，Google / Adobe，SIL Open Font License；许可在 `fonts/OFL.txt`。https://github.com/google/fonts/tree/main/ofl/notosanssc 。
- **解说**：杭州版原创稿，Microsoft Edge TTS `zh-CN-YunxiNeural`，速率 `-6%`。逐句输入、采样数与文件校验和见交付目录 `speech-manifest.json`。
- **音乐和音效**：本片代码合成的原创 D 调五声音阶、拨弦泛音、钟音、低频冲击和滤波气流。随机种子、触发时间与混音说明见 `audio-score.json`；没有使用外部音乐录音。
- **史实来源**：上城年鉴、杭州市档案局“杭州记忆”、杭州政协网、杭州市钱江新城建设管理委员会与 UNESCO 世界遗产中心；每项陈述与链接见 `facts.json`。
