# 导演与审片第一批

状态：implemented（用户已要求按讨论建议执行；真实双案例与浏览器验收完成，125 项测试通过）。

## 范围与基线

保留素材混剪和 codefilm 两条渲染路线。本轮增加共用导演技能，以及以实际编码视频为依据的审片版本和批注工具；不引入数据库、云端 Agent、作曲器或新的字幕时间来源。

可执行参考为已实测的 huashu-motion `52467f99c602b76ba86d511d37acdfe93fa1e16e`。界面沿用该参考的中央播放器、底部镜头和右侧批注结构，使用本项目独立实现，增加明确的源文件/候选/已显示视频版本状态。三维元素拾取与自由时间线编辑不属于这批范围。

## 验收先行

- 图片混剪和代码动画都提供稳定镜头 ID。审片清单统一记录实际视频摘要、尺寸、帧率、帧数、全片/局部范围、镜头、源输入摘要和可定位的配置路径。
- 生成前登记源输入和一个尚不存在的候选视频路径；生成后检查输入未改变、视频可完整解码且符合声明范围，复制成不可覆盖的审片版本，再更新最新版本指针。登记/生成失败不影响上一版。
- 旧视频不能冒充新候选；生成期间输入变化、文件损坏、镜头 ID 重复或丢失必须拒绝发布。
- 画面加载到新视频之前，界面不能声称已显示新版。下载和批注绑定明确视频版本；评论保留当时的镜头、时间、区域和源输入摘要，不自动迁移到新版。
- Agent 可从 CLI 认领批注，获得配置/源文件及当前是否已变化的信息。标记完成时必须引用有实际变化的新审片版本；旧版证据仍可读取。
- 技术完整性、内容专项验收、运动/静止等建议分开记录；未运行的 Qwen/sync.py 保持未验证。
- 实跑图片案例和太极 V3：登记首版→实际渲染→批注→更改配置/相机源码→新预览→验证。浏览器实际检查视频加载、版本切换、提交批注和完成状态。
